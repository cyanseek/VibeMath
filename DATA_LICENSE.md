# Data license and attribution

VibeMath code is MIT licensed. Data has separate provenance.

## VibeMath-authored data

VibeMath-authored structured metadata, derived feeds, conservative template explanations, and handoff packages are licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0). Attribute “VibeMath contributors” and link this repository.

## VibeMathed imports

Records imported from the [VibeMathed public dataset](https://vibemathed.com/api/dataset) remain CC BY 4.0 and must be attributed to VibeMathed. VibeMath preserves the source license on assertions and API feeds. See the [VibeMathed methodology](https://vibemathed.com/methodology).

VibeMath normalization, status vocabulary, hashes, action signals, and handoff packaging do not remove upstream attribution. The bundled snapshot may contain an attributed subset; `pnpm sync` can replace it with the complete dataset currently served upstream.

## Original mathematical sources

Paper titles, citations, short statements, repository metadata, and links point to independently licensed works. CC BY 4.0 on the catalog does not grant rights to reproduce an original paper, proof, or repository. Cite and follow each original source separately.

No source's trademark or logo is licensed through this repository.
